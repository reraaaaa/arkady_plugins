## Обзор
Anthropic предлагает набор ИИ-моделей, спроектированных с упором на безопасность и полезность, — они хорошо справляются с обработкой и генерацией естественного языка, включая написание кода и творческие задачи. С этим плагином можно легко настроить и подключить LLM из семейства Claude (Sonnet, Haiku и Opus), указав необходимые API-ключи.

## Настройка
Для настройки плагина понадобится API-ключ Anthropic. Получив его у Anthropic, введите ключ вместе с адресом API в настройках ниже и сохраните — плагин активируется.

## Опции кэширования промптов (Prompt-Caching)
API Claude позволяет помечать отдельные части запроса как *эфемерные*. Такие блоки кэшируются на стороне Anthropic, благодаря чему последующие запросы становятся дешевле и быстрее.
Плагин предоставляет точечные переключатели, позволяющие управлять тем, **что именно** кэшируется.

| Параметр | По умолчанию | Описание |
|-----------|---------|-------------|
| `prompt_caching_system_message` | `true` | Кэшировать содержимое, обёрнутое в `<cache>…</cache>` внутри системного промпта. |
| `prompt_caching_tool_definitions` | `true` | Добавляет `cache_control` к каждому определению инструмента в массиве `tools`. |
| `prompt_caching_images` | `true` | Кэширует блоки с изображениями. |
| `prompt_caching_documents` | `true` | Кэширует блоки с PDF-документами. |
| `prompt_caching_tool_results` | `true` | Кэширует блоки `tool_use` / `tool_result`. |
| `prompt_caching_message_flow` | `0` | Если задано положительным числом *N*, любое текстовое сообщение пользователя или ассистента длиннее *N* слов автоматически кэшируется. `0` отключает это авто-кэширование. |

**Ограничение Anthropic:** не более **4** блоков могут содержать `cache_control` в одном запросе.
Плагин соблюдает это ограничение, расставляя приоритеты в следующем порядке:
1. Изображения / документы
2. Блоки `<cache></cache>` в системном сообщении
3. Длинные текстовые сообщения (порог message-flow)
4. Определения и результаты инструментов

Если кандидатов больше четырёх, у блоков с более низким приоритетом `cache_control` автоматически убирается перед отправкой запроса.
