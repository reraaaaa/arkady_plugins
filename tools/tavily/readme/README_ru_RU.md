# Tavily

Инструмент Tavily подключает ваших агентов Arkady к поисковой системе, изначально спроектированной для LLM. В отличие от классических поисковых API, возвращающих сырые ссылки, Tavily отдаёт чистые, структурированные и контекстно-релевантные результаты, готовые к использованию ИИ.

## Доступные действия

| Действие       | Описание                                      | Лучше всего подходит для                                 |
| ------------ | ------------------------------------------------ | -------------------------------------------------------- |
| **Search**   | Поиск в вебе, оптимизированный под ИИ, с оценкой релевантности   | Общих запросов, актуальной информации, проверки фактов    |
| **Extract**  | Извлечение структурированного контента с конкретных URL       | Чтения статей, разбора документации, извлечения данных |
| **Crawl**    | Глубокий обход сайта по внутренним ссылкам     | Аудита сайтов, комплексного сбора данных               |
| **Map**      | Обнаружение и построение карты всех URL внутри домена        | Анализа структуры сайта, обнаружения контента            |
| **Research** | Многошаговое автономное исследование сложных тем | Подробных отчётов, маркетинговых исследований, due diligence         |

## Настройка

### 1. Получите API-ключ

Зарегистрируйтесь и получите API-ключ на [app.tavily.com](https://app.tavily.com).

Бесплатный тариф включает **1000 API-кредитов в месяц**.

![](./_assets/apikey.gif)

### 2. Установите из Plugin Marketplace

Перейдите в **Plugin Marketplace** в Arkady и найдите «Tavily». Нажмите **Install**.

### 3. Добавьте API-ключ

Перейдите в **Tools → Tavily → Authentication** и вставьте свой API-ключ.

![](./_assets/tavilytool.gif)

Запросы Tavily из интеграции Arkady включают заголовок `X-Client-Name: arkady` для атрибуции клиента.

### 4. Добавьте узел Tool в свой флоу

Добавьте Node → Tool → Tavily. Доступны все пять действий:

  <img src="./_assets/actions.png" />
</p>

## Типовые сценарии

**Проверка фактов:**
Вопрос пользователя → Search (include_answer: true) → LLM проверяет и отвечает

**Агрегация контента:**
Тема → Search → Extract (топ-URL) → LLM резюмирует

**Конкурентный анализ:**
URL конкурента → Map → Crawl ключевых страниц → LLM анализирует
