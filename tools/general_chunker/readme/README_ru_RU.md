# General Chunk

## Обзор

General Chunk — сервис, реализующий обычный режим чанкинга текста: извлекаемые
и возвращаемые (recall) чанки совпадают.

## Установка

Установите из GitHub-релиза плагина (файл `.arkadypkg`) в консоли плагинов
Arkady, либо подключите напрямую в шаблоне пайплайна через `github`-зависимость.

## Использование

Инструмент `General Chunk` можно использовать в следующих типах приложений:

#### Приложения Chatflow / Workflow

И Chatflow, и Workflow поддерживают добавление узла инструмента `General Chunk`.

#### Приложения-агенты

Добавьте инструмент `General Chunk` в приложение-агент, затем введите
инструкции для онлайн-поиска, чтобы вызвать этот инструмент.
