# Document Extractor

Document Extractor конвертирует загруженные документы в Markdown и
структурированные записи документов для RAG-пайплайнов и workflow.

## Поддерживаемые форматы

- PDF (`.pdf`)
- Microsoft Word (`.docx`)
- Microsoft PowerPoint (`.pptx`)
- Microsoft Excel (`.xls`, `.xlsx`)
- Markdown (`.md`, `.markdown`, `.mdx`)
- HTML (`.htm`, `.html`)
- CSV (`.csv`)
- JSON (`.json`)
- YAML (`.yaml`, `.yml`)
- Текстовые форматы: `.txt`, `.log`, `.rst`, `.ini`, `.cfg`, `.conf`, `.xml`

Текстовые MIME-типы также принимаются, если у файла нет распознаваемого
расширения. Неподдерживаемые бинарные форматы возвращают понятную ошибку
вместо попытки декодировать их как текст.

## Результаты

- Текстовый вывод содержит полный извлечённый Markdown.
- `documents` содержит записи в формате, соответствующем типу файла: строки
  для CSV/Excel, страницы для PDF, разделы для Markdown, и запись на весь
  файл для остальных форматов.
- `images` формируется, если встроенные или упомянутые изображения удалось
  загрузить в Arkady.

Некорректные, пустые, нераспознаваемые или превышающие лимиты ресурсов файлы
возвращают одно сообщение об ошибке и не отдают частичные переменные
документа.

## Защита от опасных изображений и архивов

Удалённые изображения в Markdown и DOCX импортируются по принципу
best-effort. Используются только HTTP(S)-адреса, таймаут запроса — 30
секунд, максимум 20 изображений, лимит 15 МиБ на изображение и 100 МиБ
суммарно. Неудачная загрузка или выгрузка изображения не приводит к потере
остального извлекаемого текста.

Office-файлы на основе ZIP отклоняются до разбора, если содержат более
10 000 записей, разворачиваются более чем в 200 МиБ или превышают
коэффициент сжатия 1000:1.

## Разработка

Плагин рассчитан на Python 3.12, для управления зависимостями используется
`uv`.

```bash
uv sync --all-groups --frozen --python 3.12
uv run pytest
uv run ruff check .
uv run ruff format --check .
```
