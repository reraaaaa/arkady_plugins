## parent_child_chunk

**Version:** 0.0.13
**Type:** tool

### Description

Parent-child chunking mode for RAG pipelines: splits documents into parent
sections and finer-grained child chunks, retrieving via child chunks while
recalling the parent context.

### Installation

Install from the plugin's GitHub release (`.arkadypkg` asset) in Arkady's
plugin console, or reference it directly from a pipeline template via a
`github` dependency.
