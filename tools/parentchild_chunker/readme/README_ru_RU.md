## parent_child_chunk

**Версия:** 0.0.16
**Тип:** tool

### Описание

Режим родитель-дочернего чанкинга для RAG-пайплайнов: разбивает документы на
родительские секции и более мелкие дочерние чанки, поиск ведётся по дочерним
чанкам, а возвращается родительский контекст.

### Установка

Установите из GitHub-релиза плагина (файл `.arkadypkg`) в консоли плагинов
Arkady, либо подключите напрямую в шаблоне пайплайна через `github`-зависимость.
