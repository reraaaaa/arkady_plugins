## cyberai-vector

**Автор:** cyberai-vector
**Версия:** 0.0.9
**Тип:** tool

### Описание

Поиск и RAG-ответы по нормативным правовым актам РФ в области информационной
безопасности (НПА РФ) и по библиотеке лучших практик ИБ, на основе сервиса
CyberAI Vector (`Arkady_Cyber/src/cyberai_vector/api.py`) — гибридный поиск
в Qdrant (плотные и разреженные BGE-M3 векторы) с реранкером
на кросс-энкодере.

### Настройка

1. Запустите сервис CyberAI Vector (`api.py`) так, чтобы он был доступен из
   этого инстанса Arkady — локально: `.venv/bin/uvicorn cyberai_vector.api:app
   --host 0.0.0.0 --port 8001`.
2. В настройках провайдера этого плагина укажите:
   - **Base URL** — адрес, по которому доступен `api.py`. Если Arkady
     запущена в Docker на той же машине, что и `api.py`:
     `http://host.docker.internal:8001`. В продовой конфигурации серверов:
     `http://10.198.96.180:8001`.
   - **API Token** (необязательно) — нужен только если на стороне `api.py`
     задан `CYBERAI_API_TOKEN`. Пусто с обеих сторон = офлайн dev-режим, без
     проверки авторизации. Если у `api.py` токен настроен, а это поле
     оставлено пустым, каждый вызов упадёт с 403.

### Использование

Два инструмента, добавьте их в приложение в режиме агента:

- **search_npa** — прямой поиск по нормативным актам РФ в сфере ИБ.
  Возвращает найденные фрагменты с полными метаданными (цитата, требование,
  юридическая сила, статус, области применения).
- **search_bestpractices** — то же самое, по библиотеке лучших практик ИБ
  (ISO/IEC 27002 и т.п.) — это не законодательство РФ, а дополнительный
  справочный материал.

Оба — это инструменты прямого поиска, рассчитанные на многократные вызовы
внутри собственного цикла рассуждений агента (несколько прицельных запросов,
перепроверка пробелов), а не на единственный одноразовый вызов — это задача
агента, а не этого плагина.
