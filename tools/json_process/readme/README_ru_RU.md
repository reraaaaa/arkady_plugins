# Обзор
JSON Process — набор инструментов для вставки, удаления, замены и разбора данных внутри JSON-структуры.

# Настройка
## JSON Insert
Инструмент JSON Insert добавляет новое значение в JSON-объект.

![](./_assets/json_insert.png)

## JSON Delete
Инструмент JSON Delete удаляет элемент из JSON-структуры.
![](./_assets/json_delete.png)

## JSON Parse
Инструмент JSON Parse преобразует строку JSON в объект JavaScript или словарь Python — в зависимости от используемого языка.
![](./_assets/json_parse.png)

## JSON Replace
Инструмент JSON Replace заменяет значения внутри JSON-объекта.
![](./_assets/json_replace.png)
